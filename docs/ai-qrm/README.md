# AI QRM Documentation Pack

This directory contains the repository artifacts needed to complete the AI QRM questionnaire for this project.

## Contents

- `evidence-map.md` — question-by-question artifact mapping (Q1–Q50)
- `system-overview.md` — system diagram, components, and data flow
- `use-cases-and-scope.md` — intended uses, users, downstream systems, and out-of-scope uses
- `model-governance-and-risks.md` — model details, risks, reliability, robustness, fairness, explainability, and data quality coverage
- `operations-monitoring-and-feedback.md` — disclaimer/feedback approach and continuous monitoring approach
- `artifacts/` — upload-ready supporting files including N/A evidence files where screenshot-based prompts do not apply to this CLI project
